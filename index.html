Documentação da Linguagem Go¶

Bem-vindo à documentação da linguagem Go desenvolvida utilizando o Zensical.

O que é Go?¶

Go (ou Golang) é uma linguagem de programação criada pelo Google com foco em:

  • Simplicidade
  • Performance
  • Concorrência
  • Escalabilidade

A linguagem é muito utilizada no desenvolvimento de:

  • APIs
  • Microsserviços
  • Sistemas distribuídos
  • Ferramentas de infraestrutura
  • Cloud Computing

Objetivo da Documentação¶

Este projeto tem como objetivo apresentar os principais conceitos da linguagem Go de forma simples e organizada.

A documentação aborda temas como:

  • Sintaxe básica
  • Estruturas de controle
  • Arrays, slices e maps
  • Structs e métodos
  • Tratamento de erros
  • Goroutines
  • Channels
  • Go Modules
  • Testes automatizados

Navegação do Site¶

Utilize o menu lateral para navegar entre os conteúdos da documentação.

As páginas estão organizadas por tópicos para facilitar o aprendizado progressivo da linguagem Go.

  • Cache de dependências
  • Upload e download de artefatos
  • Deploy automático no GitHub Pages
